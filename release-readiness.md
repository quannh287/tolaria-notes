# Release Readiness

Trước khi release cần xác nhận:

- Acceptance Criteria hoàn thành.
- Test results và evidence có sẵn.
- Target environment rõ ràng.
- Version và feature có thể truy vết.
- Migration plan đã sẵn sàng.
- Monitoring và alerts hoạt động.
- Rollback plan tồn tại.
- Operational owner được xác định.
- Support cho P1/P2 đã sẵn sàng nếu cần.

## Project-defined

Response time, error rate, uptime, capacity và các SLO khác phải do từng dự án định nghĩa.
