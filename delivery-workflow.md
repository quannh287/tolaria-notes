# Delivery Workflow

```text
Request
→ Capture in Jira
→ Clarify
→ Prioritize and align
→ Plan
→ Implement
→ Review
→ Test
→ Deploy
→ Verify
→ Demo
→ Close hoặc Create follow-up
```

## Working rules

- Jira là system of record.
- Teams hoặc Slack chỉ dùng để phối hợp.
- Quyết định, owner và trạng thái phải được cập nhật vào Jira.
- Feedback ngoài Acceptance Criteria trở thành follow-up ticket.
- Không giữ ticket đã hoàn thành mở chỉ vì xuất hiện yêu cầu mới.
- Risk phải được báo trước khi sprint commitment bị ảnh hưởng.
